# /plan-phase
Plan the phase I name. Do not write code.
1. Read AGENTS.md, docs/00_MASTER_BRIEF.md and the docs that phase depends on (docs/14 lists them).
2. Write a plan: tasks in order, files you will create or change, dependencies (reason, size, licence, risk), tests you will write.
3. List risks, assumptions and every [verify] item you must check, with how.
4. List questions for me.
5. Stop and wait for my approval.
