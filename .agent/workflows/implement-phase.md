# /implement-phase
Implement the approved plan for the phase I name.
1. Work on a new branch. Small commits with clear messages.
2. Follow api/openapi.yaml and db/schema.sql exactly. If they are missing something, stop and ask.
3. Write tests with the code. Run linters and all tests. Fix failures at the cause; never weaken a rule to pass a test.
4. Finish with the report: what changed, what was tested and results, what is uncertain, questions for me.
5. Stop for my review.
