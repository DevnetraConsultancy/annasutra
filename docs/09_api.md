# 09. API design

The contract is `api/openapi.yaml` (35 paths, validated as OpenAPI 3.0.3). It is generated by `tools/gen_openapi.py`. **The agent must not add or change endpoints or fields without human approval.**

## Conventions

- Base path `/v1`. Breaking changes go to `/v2`.
- JSON. Errors use `application/problem+json` with a stable `code`.
- Auth: `Authorization: Bearer <token>`. Public page and OTP request routes have no token.
- Every write requires `Idempotency-Key` (a UUID) **and** a client-made `event_id`. Same key returns the same result.
- Lists use cursor pagination: `?limit=50&cursor=...`.
- Every handler checks: caller's organisation and role, lot state, strict body schema, unknown fields rejected.
- The same error is returned for "not found" and "not allowed" where existence would leak information.
- Rate limits: strict on `/v1/auth/*`, `/v1/public/*`, `/v1/sync/*` (Cloudflare and app level).

## Endpoint groups

| Group | Endpoints |
|---|---|
| Auth | request OTP, verify OTP (registers device key), refresh, passkey register and login (options + verify), register, list and revoke devices |
| Organisations | register business or farmer, list partners, invite partner, accept invitation |
| Labels | request a serial block |
| Lots | create, list, get, history, inspect, split, merge, sort, repack, waste, sales, label reissue |
| Custody | dispatch, receive, dispute, resolve |
| Corrections | append a correction to an event |
| Evidence | request a signed upload URL |
| Sync | submit queued events in a batch (up to 100) |
| Recall | open, forward-trace report |
| Public | consumer summary (no login) |

## Examples

**Create a lot**
```http
POST /v1/lots
Idempotency-Key: 0191f3c2-7a1e-7b2a-9d41-2c8e5a0b11f4
Authorization: Bearer ...
{
  "event_id": "0191f3c2-7a1e-7b2a-9d41-2c8e5a0b11f4",
  "label_serial": "7K3Q9XMD4T2B",
  "product": {"name": "Tomato", "variety": "Hybrid"},
  "harvest_date": "2026-10-06",
  "net_qty_kg": 500.0,
  "qty_basis": "MEASURED",
  "crates": 20,
  "event_time": "2026-10-06T16:30:00+05:30"
}
-> 201 {"lot_id":"...","public_code":"7K3Q9XMD4T2B","state":"CREATED","on_hand_kg":500.0,"lot_seq":1}
```

**Custody conflict**

```json
{"type":"https://api.example.in/errors/custody","title":"Not current custodian",
 "status":409,"detail":"Lot is IN_TRANSIT to another organisation.","code":"CUSTODY_CONFLICT"}
```

**Sync batch result** (per item, in order)

```json
{"results":[
  {"event_id":"...","status":"ACCEPTED","lot_seq":4},
  {"event_id":"...","status":"CONFLICT","reason_code":"HANDOVER_ALREADY_RECEIVED","message":"Another receipt was accepted first."}
]}
```

```json
{"code":"4H8Z2QWA9PD3","product":"Tomato (hybrid)","harvest_date":"2026-10-06",

```

## Validation rules (examples)

- `qty_kg` greater than 0, at most 3 decimals, upper sanity limit per event.
- `event_time` not far in the future.
- `label_serial` must be issued to the caller's organisation and unbound.
- Dispatch quantity cannot exceed on-hand. Receiver must be a trusted partner.
- Split children plus remainder cannot exceed on-hand.

## Integrations (no invented interfaces)

| System | Approach | Status |
|---|---|---|
| APEDA (HortiNet, TraceNet and others) | Export CSV or PDF packs for exporters. Use the official portal until a documented interface exists | No public API confirmed |
| e-NAM | Reference the mandi lot number as a text field. Pursue an official data-exchange agreement later | No public API confirmed |
| FSSAI | Store licence number. Export records for inspection and recall | No known API |
| Laboratories | Certificate upload with accreditation and certificate numbers | No feed confirmed |
| Weighbridges and scales | Manual entry plus scale-display photo. Bluetooth scale integration later | Not in v1 |
| GS1 partners | EPCIS 2.0 JSON export adapter later | Standards-based |
